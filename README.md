# Lagos CleanMove — Final Prototype

## Install

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Routes

- `/` Home
- `/routes` Routes
- `/trucks` Fleet control
- `/map` GPS + map
- `/coverage` Lagos coverage
- `/markets` Market operations
- `/collection-points` Bins / collection points
- `/report` Citizen report
- `/about` Project explanation

## Image assets

- `hero-transport.svg` — full-width transparent-style hero transport illustration

## Data integrity

- Lagos waste generation and LAMATA transport figures are source-backed context used for presentation.
- Truck positions/counts, bus availability and collection-point fill levels are demo UI data.
- The Cotonou unit is labelled as a concept, not a claim of a confirmed Lagos-Cotonou truck loan.
- Market truck frequencies are proposed planning scenarios, not current government allocations.
